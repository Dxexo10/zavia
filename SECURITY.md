# Política de seguridad

No abras incidencias públicas para reportar una vulnerabilidad.

Usa el formulario privado de reporte de vulnerabilidades de GitHub disponible en la pestaña
**Security** de este repositorio. Incluye una descripción, impacto, pasos de reproducción y,
si corresponde, una corrección propuesta.

Se confirmará la recepción en un plazo máximo de siete días y se coordinará el tratamiento de
forma privada. No publiques detalles hasta recibir confirmación de que la corrección está lista.
